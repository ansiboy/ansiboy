## 🧑‍💻 About Me | 关于我

> 写框架，也写业务。早年在 .NET 生态做 ORM 与开发工具（ALinq、Visual Entity、ALinq Dynamic / Inject），后来转向 TypeScript 前端与混合 APP（ChiTu、ChiTuStore），再到可视化页面设计器（jueying、page-builder），以及网站性能、SEO、ERP 打印、门店广告播放这类真实业务系统。博客园从 2010 年写到现在，GitHub 上有 105 个公开仓库。
>
> *I write frameworks and I ship businesses. Started with .NET ORMs & dev tools (ALinq, Visual Entity, ALinq Dynamic/Inject), moved to TypeScript front-ends and hybrid apps (ChiTu, ChiTuStore), then visual page builders (jueying, page-builder), and real-world systems: web performance, SEO, ERP printing, in-store ad playback. Blogging on CNBlogs since 2010; 105 public repos on GitHub.*

- 🌱 **当前在做 | Now**：全栈开发与开源；2026 年新建 `alinq.js`，并持续把 node-shop-v2（SaaS 建站平台）的架构实践沉淀成文档与演示。
- 💬 **技术理念 | Philosophy**：*“好的架构不是想出来的，而是做来的。”* —— Good architecture is built, not imagined.
- 📝 **博客 | Blog**：[博客园 cnblogs.com/ansiboy](https://www.cnblogs.com/ansiboy)（2010 至今）
- 🔗 **个人站 | Site**：[maishu.uk](https://maishu.uk)
